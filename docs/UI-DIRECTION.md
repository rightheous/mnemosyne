# 공통 UI 방향

한국어를 기본으로 하는 조용한 공부 화면. 원문 PDF가 중심이고 Tutor와 학습 기록은 읽는 흐름을 돕는다. 기존 upstream 사용자 화면을 Mnemosyne의 용어·흐름으로 재설계한다.

## 용어

| 공통 label | 뜻 |
|---|---|
| 라이브러리 / 과목 / 문서 | Library / subject / PDF |
| 튜터 / 문서와 대화 / 읽기 도움 | Tutor / Chat / Reading |
| 퀴즈·평가 / 숙련도 / 심화 풀이 | Quiz/Assessment / Mastery / Deep Solve |
| 기억 카드 / 학습 기록 / 복습 | Memory / Progress / Review |
| 하이라이트 / 노트 / 북마크 / 필기 | 영구 주석 종류 |
| 근거 보기 / 페이지로 이동 | 검증된 인용 연결 |
| 잠깐 강조 | 일시 효과; 주석을 저장하지 않음 |
| 기기에 저장됨 / 동기화 중 / 충돌 확인 | 로컬 durable 상태 / 전송 중 / 사용자 해결 필요 |
| 읽기 가능 / 분석 중 / 학습 준비 완료 / 분석 실패 | Reader와 Tutor 준비 상태 구분 |

문서 언어와 응답 언어는 별도 설정이다. 기본 응답 한국어, 문서 언어 자동 감지 결과는 수정 가능. 인용문·수식·코드는 원문을 표시한다. 페이지 label은 PDF의 page label 또는 물리 페이지+1이며 링크는 항상 물리 index 0 기반을 사용한다.

## Mac 웹

왼쪽 탐색에 과목 목록, 라이브러리, 학습 기록/복습, 설정을 둔다. 라이브러리는 과목 필터, 제목 검색, 업로드, 분석 상태, 다운로드/삭제를 제공한다. 과목 생성·이름 변경·문서 과목 이동을 지원한다.

문서 화면은 PDF 중앙, 우측 Tutor/퀴즈/노트 패널이다. 위쪽에 제목·페이지 이동·검색·목차·주석 내보내기, 하이라이트/노트 도구를 둔다. iPad 필기는 같은 geometry로 표시하고 편집 제어를 두지 않는다. 인용 칩은 `p. 12 · 근거 보기`처럼 표시한다. Tutor에서 퀴즈, 기억 카드, 숙련도와 복습 화면으로 연결하고 결과 저장 상태를 표시한다. 모델/서버 설정은 일반 탐색의 설정에 둔다. 비밀값 입력 후에는 설정 여부만 표시한다.

## iPad

가로: 과목/Library sidebar를 접을 수 있고 PDF 옆에 Tutor를 둔다. PDF 작업 영역과 Pencil 도구는 계속 사용할 수 있다. 세로: PDF가 주 영역이며 Tutor는 높이를 조절하는 sheet로 열어 같은 문서를 유지한다. 긴 노트/퀴즈는 펼칠 수 있다. 회전해도 읽기 위치와 필기 좌표가 변하지 않는다.

도구는 펜, 형광펜, 지우개, undo/redo, 색/굵기, 텍스트 하이라이트, 노트, 북마크다. 터치 스크롤과 Pencil 입력을 구분한다. 다운로드된 PDF에는 `오프라인 읽기 가능`을 표시한다. 네트워크가 끊겨도 필기 저장 상태는 즉시 표시하며, 서버 연결 실패로 필기 입력을 막지 않는다. Tutor 요청이 연결을 요구하면 그 상태를 해당 패널에 표시한다.

## 가벼운 시각 규칙

- 배경 `#F5F6F8`, 표면 `#FFFFFF`, 본문 `#1F2937`, 보조 `#667085`, accent `#315DA8`. 선택 강조는 낮은 불투명도 청색, 저장된 형광펜은 사용자가 고른 색. 오류는 텍스트와 아이콘으로 함께 표시한다.
- 본문은 시스템 글꼴, UI 기본 16px/17pt, 편안한 행간. PDF 원문 글꼴/내용은 바꾸지 않는다. 숫자와 페이지 위치는 명확하게 표시한다.
- 여백은 4/8/12/16/24 단위, 모서리는 8 정도, 그림자는 최소화. 터치 표적은 iPad 44pt 이상. 키보드 탐색과 focus, VoiceOver label, 색 외 상태 표시를 제공한다.
- 일시 강조는 짧게 표시하고 접근성 motion 설정을 따른다. 영구 주석 작성은 별도 명시 action이다. 스트리밍 중 취소, 재연결, 실패, 완료 상태를 사용자가 볼 수 있다.

실제 폰트·component 라이브러리는 upstream 확인 후 기존 스택에 맞춘다. 이 문서 때문에 새 UI 프레임워크를 도입하지 않는다.
